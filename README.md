# Скиллы для ИИ-агента Lite

Готовые «навыки» для персонального агента [lite.panteo.ai](https://lite.panteo.ai): вы отдаёте
агенту ссылку на папку скилла — он читает инструкцию и настраивает всё сам, задавая вам вопросы
только там, где нужны ваши доступы.

| Скилл | Что агент начинает уметь |
|---|---|
| [`skills/multipost`](skills/multipost/SKILL.md) | Один пост из мессенджера → Telegram, MAX, Facebook, Instagram, Threads. Картинки под каждый формат, согласование одного текста, остальное автоматически |
| [`skills/videomontage`](skills/videomontage/SKILL.md) | Сырое видео с телефона → готовый ролик: паузы и самоповторы вырезаны, ни одного среза по живому слову, субтитры на месте, таймлайн для монтажки. Вертикаль для шортсов и горизонталь для YouTube/VK/Rutube |
| [`skills/nutrition-coach`](skills/nutrition-coach/SKILL.md) | Личный диетолог: журнал питания по фото и тексту, дашборд дня, прогноз даты цели, напоминания и тренировки |

## Как этим пользоваться

1. **Заведите агента.** Инструкция и тарифы — на [lite.panteo.ai](https://lite.panteo.ai).
   Агент живёт в мессенджере: Telegram или MAX, отдельный чат = отдельный исполнитель.
2. **Отправьте агенту ссылку на скилл**, например:

   ```
   Возьми скилл https://github.com/wybaeb/lite-skills/blob/master/skills/multipost/SKILL.md
   и настрой его у меня. Спрашивай, если нужны доступы.
   ```

3. **Ответьте на вопросы про доступы.** Токены и пароли передавайте через хранилище секретов
   вашего агента (в чате это команда `/secrets`), а не текстом в переписке.
4. **Первый прогон — всегда «вхолостую»**: агент показывает, что получится, и только после
   вашего «да» публикует, монтирует или пишет в календарь.

## Что здесь НЕ лежит

Никаких токенов, паролей, номеров каналов, персональных данных и содержимого чужих аккаунтов.
Только инструкции и шаблоны конфигов с плейсхолдерами. Всё, что специфично для вас, агент
запрашивает у вас и хранит в вашем секрет-сторе.

## Принципы, общие для всех скиллов

- **Приёмка обязательна.** Агент не публикует, не удаляет и не тратит деньги без вашего явного «да».
- **Черновик прежде прода.** Есть тестовый канал/папка — сначала туда.
- **Развилку с ценой приносит человеку.** Не «я решил», а «вариант А стоит столько, вариант Б столько».
- **Секреты — только по имени.** В логах, отчётах и коде значений быть не должно.
