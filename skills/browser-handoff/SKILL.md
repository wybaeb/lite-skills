# Browser handoff в Lite

Этот навык использует платформенный browser broker. Не поднимай Docker, VNC, Chrome или
туннель самостоятельно и не проси Docker socket. Изолированный browser-sidecar запускает
мост, а приватную ссылку создаёт мост для текущего пользователя.

## Обязательная последовательность

1. До запуска одной фразой зафиксируй границу задачи: чтение, черновик, заполнение или
   финальное внешнее действие. Для отправки, покупки, публикации и удаления всё равно нужно
   обычное явное подтверждение пользователя.
2. Покажи мягкое предупреждение:

   > Не входите через этот браузер в банки, Госуслуги и криптокошельки. Такие сценарии
   > запрещены условиями Lite и могут привести к остановке сервиса. Платформа передаёт
   > владельцу только обезличенный сигнал риска без адреса страницы и содержимого.

   На этом этапе предупреждение и сигнал риска **не блокируют браузер автоматически**:
   решение о приостановке принимает владелец сервиса.
3. Попроси пользователя отправить `/browser` в этом же чате. Эта команда одновременно
   проверяет, что capability включена для аккаунта. Ссылку создаёт и присылает
   мост; сам агент её не вычисляет, не копирует из логов и не обещает до ответа команды.
   Не показывай внутренние адреса, VNC-пароль, lease id или CDP.
4. Напиши пользователю:

   > Откройте защищённый браузер, войдите сами и вручную пройдите 2FA/CAPTCHA. Пароль и
   > коды сюда не присылайте. Когда нужная страница открыта, нажмите «Передать агенту».

5. Сообщение «готово» в чате само по себе не даёт доступа. После кнопки «Передать агенту»
   проверь `http://127.0.0.1:9222/json/version`; до handoff адрес обязан быть недоступен.
   Не делай частый retry-loop: достаточно нескольких проверок с паузой.
6. После успешной проверки используй минимальный CDP helper из
   [cdp-helper.md](references/cdp-helper.md), создай свою вкладку и выполняй только
   согласованный объём. Не экспортируй cookies/storage state и не читай секретные поля.
7. Один handoff даёт не более 15 минут автоматизации. Агент не управляет lease через
   отдельный API. По окончании попроси пользователя нажать «Отозвать управление» или
   «Закрыть браузер»; если время вышло — пользователь повторяет handoff. Профиль и вход
   сохраняются между handoff, пока пользователь сам не удалит профиль.

## Риски банков, государства и криптовалют

Если по контексту задачи стало ясно, что пользователь открыл банк, Госуслуги или
криптокошелёк:

- повтори предупреждение и не проси данные для входа;
- отправь best-effort advisory через `node "$CODEX_HOME/skills/browser-handoff/scripts/browser-advisory.mjs" bank`,
  `government` или `crypto`;
- не включай URL, название сайта, аккаунт, снимок, текст страницы или секрет в сигнал;
- не бань пользователя и не закрывай браузер автоматически только по эвристике;
- необратимое действие не выполняй без отдельного явного подтверждения.

Если advisory недоступен, не обходи его собственным логом или сообщением с адресом страницы:
укажи в техническом статусе только то, что обезличенный сигнал не доставлен.

## Инварианты

- Секреты вводит только человек в удалённом браузере. Никогда не проси пароль, 2FA,
  cookies, токены или ответ CAPTCHA в чат и не вводи их за пользователя.
- До handoff raw CDP отсутствует. Если CDP отвечает раньше состояния `agent`, прекрати
  работу и сообщи об ошибке изоляции.
- HTML и WebSocket приватного браузера используют одну web-auth Lite. Длинная или скрытая
  ссылка без аутентификации защитой не считается.
- Порты 5900/6080/9222 не публикуются Docker и не доступны из интернета. Docker socket
  внутри пользовательского контейнера запрещён.
- Профиль браузера отделён от home агента, имеет одного владельца и одного писателя; не
  попадает в Git, outbox, диагностические архивы и квоту проектов.
- Не обходи антибот-защиту, не подключай сервис CAPTCHA, не маскируй отпечаток и не вращай IP.
- Если правила сайта запрещают автоматизацию, используй официальный API или верни работу
  человеку.

## Критерий завершения

- capability подтверждена ответом моста на `/browser`, и мост выдал персональную ссылку;
- пользователь самостоятельно прошёл вход/2FA/CAPTCHA;
- агент получил lease только после кнопки handoff;
- результат проверен чтением, внешнее действие подтверждено;
- lease отозван, raw CDP закрылся, профиль сохранён;
- в чате, логах, Git и advisory нет секретов, URL и содержимого страницы.
